# 归档目录说明

本目录用于存放一次性测试文件和过期的分析报告文档，以保持项目根目录的整洁。

## 目录结构

```
archive/
├── analysis_reports/     # 过期的分析报告文档
└── test_scripts/         # 一次性测试脚本
```

- `指标计算架构分析.md` - 指标计算架构分析

- `测试Mock和CARLA调用分析报告.md` - 测试Mock和CARLA调用分析报告（2024-12-11）
