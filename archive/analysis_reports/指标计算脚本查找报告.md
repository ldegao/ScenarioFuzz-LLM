# 指标计算脚本查找报告

## 查找结果总结

经过详细查找，**没有找到从场景数据（JSON/pickle文件）重新计算指标的专门脚本**。

现有的脚本都是**读取已经计算好的指标值**，而不是从原始场景数据计算。

## 现有相关脚本

### 1. 指标聚合脚本（读取已计算的指标）

#### `experiments/aggregation/metrics_aggregator.py`
**功能**：
- 读取 `metrics_records.jsonl`（包含已经计算好的指标值）
- 聚合这些值生成 `metrics_summary.json`
- **不计算指标**，只做聚合统计

**使用方式**：
```bash
python -m experiments.aggregation.metrics_aggregator \
    --records path/to/metrics_records.jsonl \
    --output path/to/metrics_summary.json
```

**位置**：`experiments/core/experiment_manager.py` 第1077-1095行
- 在实验归档时自动调用
- 读取 `metrics_records.jsonl` 并聚合

### 2. 指标分析脚本（分析已计算的指标）

#### `experiments/analysis/compare_similarity_methods.py`
**功能**：
- 读取多个实验的 `metrics_summary.json`
- 对比不同方法的指标
- 生成对比报告和图表

#### `experiments/analysis/scenario_analysis.py`
**功能**：
- 读取 `metrics_records.jsonl`
- 分析场景级别的指标分布
- 识别异常场景
- 分析模式

#### `experiments/aggregation/collect_results.py`
**功能**：
- 扫描所有 `metrics_summary.json` 文件
- 收集到统一的 `all_methods_results.json`

### 3. 指标计算位置（当前实现）

#### `fuzzer.py` 第958-1012行
**功能**：
- **在场景执行后立即计算指标**
- 使用累积场景列表计算
- 保存到 `metrics_records.jsonl`

**问题**：
- 指标计算混在fuzzer中
- 无法离线重新计算
- 如果计算逻辑改变，需要重新运行实验

## 缺失的功能

### 应该存在但未找到的脚本

**期望的脚本**：`experiments/analysis/calculate_metrics.py` 或类似

**应该的功能**：
1. 读取实验目录中的所有场景文件（JSON或pickle）
2. 从场景数据中提取state信息
3. 重新计算指标（PC, PEC, TCD, BCM）
4. 保存到 `metrics_records.jsonl` 和 `metrics_summary.json`

**优点**：
- 可以随时重新计算指标
- 不依赖fuzzer运行时的计算
- 可以修复指标计算bug后重新计算
- 可以对比不同的指标计算方法

## 数据流分析

### 当前数据流

```
场景执行 (fuzzer.py)
    ↓
保存场景数据 (JSON + pickle)
    ↓
立即计算指标 (fuzzer.py evaluation函数)
    ↓
保存指标值 (metrics_records.jsonl)
    ↓
聚合指标 (metrics_aggregator.py)
    ↓
生成摘要 (metrics_summary.json)
    ↓
分析脚本读取摘要进行分析
```

### 期望的数据流（更好的设计）

```
场景执行 (fuzzer.py)
    ↓
保存场景数据 (JSON + pickle) ← 只做这个
    ↓
    ↓
专门的指标计算脚本 ← 缺失！
    ↓
读取场景数据
    ↓
计算指标
    ↓
保存指标值 (metrics_records.jsonl)
    ↓
聚合指标 (metrics_aggregator.py)
    ↓
生成摘要 (metrics_summary.json)
```

## 结论

1. **没有专门的指标计算脚本**：所有脚本都是读取已计算的指标值
2. **指标计算只在fuzzer中**：这导致了之前分析的所有问题
3. **需要创建专门的脚本**：从场景数据重新计算指标

## 建议

创建 `experiments/analysis/calculate_metrics.py` 脚本，实现：
- 从场景JSON/pickle文件读取数据
- 重新计算所有指标
- 支持增量计算（只计算新场景）
- 支持重新计算（覆盖已有指标）

这样可以将指标计算从fuzzer中分离出来，实现更好的架构设计。
